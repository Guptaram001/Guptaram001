## 🚀 Current Projects

### CuRAG – Knowledge Graph Curation System

CuRAG is a research driven system for automated extraction of information from scientific papers and its integration into a Neo4j based knowledge graph. The project also provides a web interface that enables domain experts to curate, validate, and modify extracted knowledge.

#### Features

- Automated information extraction from scientific papers
- Knowledge graph construction using Neo4j
- Web interface for graph curation and validation
- Support for editing nodes, relationships, and metadata
- Human-in-the-loop workflow for knowledge verification

#### Tech Stack

Python · React · Neo4j · Knowledge Graphs · Information Extraction · Full-Stack Development

### Semantic Search on German Historical Speech Corpus (RAG System)

Performing searches across a multilingual corpus of historical speeches using **Retrieval-Augmented Generation (RAG)** with **LLMs** and **Elasticsearch**.

This project implements a Retrieval Augmented Generation (RAG) system for semantic search over a multilingual corpus of historical German speeches. It combines information retrieval techniques, vector embeddings, and large language models to enable context aware query answering.

#### Features

- Semantic search over historical speech transcripts
- Hybrid retrieval using Elasticsearch and vector embeddings
- RAG pipeline integrating LLMs for response generation
- Data preprocessing and structured indexing
- Basic evaluation of retrieval relevance

#### Tech Stack

Python · Elasticsearch · LLMs · Vector Embeddings · Information Retrieval

### INDs Finder Using Akka

This project implements a distributed system for discovering Inclusion Dependencies (INDs) across multiple datasets using the Akka Actor Model. The system is designed for scalable and efficient processing of large attribute spaces.

#### Features

- Distributed computation of Inclusion Dependencies (INDs)
- Actor-based parallel processing using Akka
- Scalable architecture for handling large datasets
- Optimized task partitioning and asynchronous execution
- Performance-focused design for large attribute sets

#### Tech Stack

Akka · Actor Model · Java · Concurrency · Distributed Systems · Data Profiling

### Multimodal Data Augmentation on Oxford-102 Flowers Dataset

This project explores a multimodal data augmentation pipeline to improve image classification performance on a limited dataset. Synthetic training data is generated using vision language and diffusion models, followed by semantic filtering and classifier evaluation.

#### Features

- Data augmentation pipeline for low data image classification
- Synthetic image generation using Stable Diffusion guided by BLIP-2 captions
- Semantic filtering of generated samples using CLIP embeddings
- Quality control to remove noisy or off class images
- Performance comparison between baseline and augmented datasets

#### Results

- Trained ResNet-50 classifier on baseline and augmented datasets
- Achieved ~5% improvement in Top-1 accuracy using augmented data

#### Tech Stack

Python · PyTorch · BLIP-2 · Stable Diffusion · CLIP · ResNet-50 · Computer Vision

### Multilabel Emotion Detection using Transformer Models

This project implements a multilabel emotion detection system using transformer based language models to classify text into five emotion categories. The work focuses on robust preprocessing, handling class imbalance, and optimizing model performance for multilabel classification tasks.

#### Features

- Multilabel emotion classification using BERT, RoBERTa, and DistilBERT
- Data preprocessing and augmentation pipeline
- Handling class imbalance through oversampling techniques
- Hyperparameter optimization using Optuna
- Model evaluation using precision, recall, F1-score, and AUPRC
- Comparative analysis and visualization of model performance

#### Results

- Achieved strong multilabel classification performance:
  - Micro F1-score: 73.9%
  - Macro F1-score: 72.4%

#### Tech Stack

Python · PyTorch · Transformers · BERT · RoBERTa · DistilBERT · Optuna · NLP
